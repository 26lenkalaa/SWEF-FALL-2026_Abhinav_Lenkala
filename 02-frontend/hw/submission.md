## Next.js vs raw HTML/CSS

Next.js helps automate and streamline the process of creating structure for a webpage compared. It still uses HTMl and CSS, but it allows for reuse of components and makes it easier to create new pages. 

## How the tools fit together
Tailwind is the artistic portion of the website. It helps create visuals and makes it prettier, and its classes are what allowed me to adjust the image crop, background colors, and font styling. React is used to build the parts of the website, like my nav bar and project cards, as reusable components. Next.js acts as the structure that everything is placed on. It creates new pages through folders, wraps every page in a shared layout, and uses React to turn my components into HTML that the browser can display.
